# Raj Gupta — Portfolio

Personal portfolio site built with Next.js 16, React 19, and Tailwind CSS v4. Deployed on Vercel.

Live at [rajg.tech](https://www.rajg.tech)

## Stack

- **Framework** — Next.js 16 (App Router)
- **Styling** — Tailwind CSS v4
- **Database** — Supabase
- **Deployment** — Vercel

## Sections

- **Hero** — Ghibli-style illustration with typewriter text
- **About** — Background and intro
- **Work** — Projects and case studies
- **Skills** — Technologies and tools
- **Contact** — Get in touch
- **Blog** — Writing at `/blog`

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment Variables

Create a `.env` file:

```
NEXT_PUBLIC_SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
MEDIUM_RSS_URL=
CRON_SECRET=
NEXT_PUBLIC_SITE_URL=
```
